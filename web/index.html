Core Features

주요 핵심 기능

🥗

점심시간 자동 절전

점심시간(기본 12:00)이 되면 60초 안내 카운트다운 후 PC를 자동으로 절전 모드로 전환합니다.

⏰

퇴근시간 시스템 자동 종료

퇴근시간(기본 18:00)에 60초 안내 알림 후 PC를 완전 종료합니다. 야근 시 1클릭으로 즉시 취소 가능합니다.

🖥️

유휴 시간 화면 절전

자리를 비워 키보드/마우스 입력이 없을 경우 설정된 시간 후 모니터 전원만 자동으로 끕니다.

📅

평일 전용 & 부팅 시 자동실행

주말(토, 일)에는 불필요하게 켜지거나 꺼지지 않으며, Windows 부팅 시 백그라운드에서 자동 실행됩니다.

User Manual

간편 설치 및 사용 방법

1

프로그램 다운로드

상단의 [다운로드] 버튼을 클릭하여 단일 실행 파일(EcoPowerManagerPro.exe)을 다운로드합니다.

2

원하는 시간 설정

점심시간, 퇴근시간, 화면 끄기 시간을 입력하고 'Windows 부팅 시 자동 실행'을 체크합니다.

3

자동 관리 시작

[▶ 자동 관리 시작]을 누르면 프로그램이 자동으로 우측 하단 시스템 트레이로 숨겨져 백그라운드 관리됩니다.

FAQ

자주 묻는 질문

Q. 퇴근시간에 야근이나 긴급 업무 중이면 어떻게 하나요?
A. 퇴근 시간이 되면 60초 전 카운트다운 알림 창이 화면 최상단에 나타납니다. 이때 [종료 취소 (야근)] 버튼을 클릭하시면 당일 예약 종료가 안전하게 취소됩니다.
Q. 숨겨진 프로그램 창은 어떻게 다시 여나요?
A. 윈도우 우측 하단 작업표시줄의 시스템 트레이(▲ 모양) 아이콘에서 초록색 나뭇잎 아이콘을 더블클릭하거나 마우스 우클릭 후 [설정 열기]를 클릭하시면 됩니다.
Q. 스마트스크린(SmartScreen) 또는 보안 경고가 나타납니다.
A. 자체 제작 내부 배포 프로그램의 경우 공인 인증서 서명이 없어 나타날 수 있습니다. [추가 정보] → [실행]을 클릭하시면 정상 실행됩니다.
